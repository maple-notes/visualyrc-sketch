# Visualyrc Sketch — Hackathon Starter

Planning pack for a new web app. **Draft, not yet approved.** No implementation has started.

## Product thesis
One project, many independent infinite canvases, a project-wide microblog-style idea inbox (**Saezutter**), and a graph connecting any content item regardless of where it appears. Music sections are an optional organizing axis, not a prerequisite.
